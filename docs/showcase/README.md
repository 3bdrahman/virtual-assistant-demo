# Showcase capture

`demo.mp4` and `demo.webm` are the same roughly 12-second recording of a real NVIDIA chat and Magpie speech response through the local visitor-key relay on October 9, 2026. Its audio was captured from the page's Web Audio output in the same browser session, then aligned with the screen recording. Key-entry frames and a long provider wait were removed. The clip demonstrates the rendered experience; its edited duration is not a response-time measurement. Both formats played with an audio track in Chromium; WebM also played in Firefox on the test host, whose H.264 decoder could not open the MP4.

`first-visit.png` shows the public GitHub Pages onboarding screen with the avatar loaded. `live-conversation.png` shows the real-provider conversation used in the voice recording. The API key is absent from these artifacts.
